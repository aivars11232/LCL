2. LANGUAGE BOUNDARY

The language consists of the source notation, vocabulary, types, grammar,
semantics, core contracts, versioning rules, and conformance requirements in this
package. An implementation is not part of the language.

A UI, IDE, workspace manager, provider connector, database, parser executable,
compiler, runtime, agent framework, and domain extension are separate products or
implementations. Their absence does not make the language archive incomplete.

3. INTERPRETATION INPUT

that source as normative task input. Unreferenced chat history, hidden memory, or
provider defaults cannot alter LCL meaning.
