1. CANONICAL SOURCE

This package root is the only canonical source tree for LCL Core 0.3.0. Language
meaning is determined by the artifacts inside this tree under
00_RELEASE/02_NORMATIVE_AUTHORITY_ORDER.txt. Files outside this package root are
not normative inputs to the language.
