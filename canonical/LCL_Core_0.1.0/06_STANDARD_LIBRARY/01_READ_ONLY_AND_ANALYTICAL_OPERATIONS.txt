core.inspect
    Meaning: Observe metadata or structure without changing the target.
    Determinism category: deterministic
    Determinism source: Exact metadata projection from the resolved target snapshot under the selected implementation version.
    Possible dependencies: {host, network}
    Possible effects: {none}
    Invocation resolution: Resolve host for PATH, host-bound, or host-backed REFERENCE access and host plus network for URI access; otherwise resolve declared_state_only. A depth outside 0..100 produces error.value.out_of_range. The invocation has no effects.
    Result schema: result.value

    Possible dependencies: {host, network}
    Possible effects: {none}
    Invocation resolution: Resolve dependencies from the target address class and requested range or format; URI access adds network. The invocation has no effects.
    Result schema: result.value

core.analyze
    Meaning: Derive stated findings from declared input.
    Determinism category: nondeterministic
    Determinism source: The base model or analytical method may vary only within the declared criteria and method constraints.
    Possible dependencies: {host, network, model}
    Possible effects: {none}
    Invocation resolution: Resolve exactly one immutable analysis profile for every invocation, then resolve model from the selected analytical method and host or network from an addressable target. A non-generative deterministic analysis profile may narrow the nondeterministic base only under axis_contract.implementation_profile; any kind.operation DETERMINISTIC TRUE is checked afterward against the resolved final category.
    Result schema: result.value

core.calculate
    Meaning: Compute a result from declared values and rules.
    Determinism category: deterministic
    Determinism source: The registered expression, binding, numeric, division, and rounding rules fix the result.
    Possible dependencies: {declared_state_only}
    Possible effects: {none}
    Invocation resolution: Use only the declared target value, expression, bindings, and declared snapshots. Evaluate MISSING and UNKNOWN under operators_and_functions_v0.1.0.json#/evaluation_contract, including ==, !=, and EXISTS exceptions; a required final MISSING result produces error.required.missing and UNKNOWN produces error.value.unknown. A host-capacity failure is error.host.constraint and does not change the dependency class. Parse and bind the exact expression_fragment_contract; no alternate calculation language is admitted.
    Error resolution: Union local errors with every applicable diagnostic of the decoded expression; wrong reference declaration kind uses error.reference.kind.
    Result schema: result.value
    Fragment contract: expression follows operations_v0.1.0.json#/expression_fragment_contract; STRING or REF to a kind.constant STRING contains exactly one existing EXPRESSION. bindings uses exact non-shadowing simple names; reserved target is TARGET or MISSING.

core.compare
    Meaning: Compare artifacts or values against exact criteria.
    Determinism category: deterministic
    Determinism source: The resolved operand snapshots and exact comparison criteria fix the result.
    Possible dependencies: {host, network}
    Possible effects: {none}
    Invocation resolution: Resolve host or network independently for the target and against operands; material-value-only comparison resolves declared_state_only. When criteria is omitted, use the registered == exact strict-equality comparison over the resolved operands. Evaluate the single criterion under the registered operator and sentinel rules: a non-==/!= criterion encountering MISSING produces error.required.missing, and a criterion whose result remains UNKNOWN produces error.value.unknown because a successful result.value must contain a material value. The invocation has no effects.
    Result schema: result.value
    Criteria contract: Exactly one registered binary comparison token STRING, or a closed OBJECT with required operator and optional left/right property_path strings, or REF to such a declared value. Omitted paths select whole operands. result.value.value is one BOOLEAN, and FALSE is a successful comparison result.

core.select
    Meaning: Choose members satisfying a predicate.
    Determinism category: nondeterministic
    Determinism source: No mandatory strategy pins returned cardinality, complete subset, or order even when every returned member satisfies the predicate.
    Possible dependencies: {declared_state_only}
    Possible effects: {none}
    Invocation resolution: Evaluate a type-compatible predicate from declared values and snapshots. A predicate result of MISSING produces error.required.missing and UNKNOWN produces error.value.unknown. A referenced kind.operation must resolve to deterministic, side-effect-free behavior with dependencies exactly declared_state_only; no invocation may add a dependency or effect.
    Error resolution: Union the local errors with every applicable error of the referenced predicate operation when a predicate REFERENCE is selected. A STRING predicate retains all applicable expression diagnostics.
    Result schema: result.collection
    Selection contract: Every result member is one target member occurrence for which the predicate is TRUE, and no target occurrence is returned more than once. Cardinality may range from zero through the number of TRUE target member occurrences; the selected TRUE subset and result order are otherwise unspecified.

core.filter
    Meaning: Return all members of one LIST that satisfy a predicate, preserving source order.
    Determinism category: deterministic
    Determinism source: All and only TRUE members are returned in their exact LIST source order.
    Possible dependencies: {declared_state_only}
    Possible effects: {none}
    Invocation resolution: Resolve the predicate to a deterministic side-effect-free expression over declared values or a kind.operation whose fully resolved dependency set is exactly declared_state_only. A predicate result of MISSING produces error.required.missing and UNKNOWN produces error.value.unknown. No invocation may add a dependency or effect.
    Error resolution: Union the local errors with every applicable error of the referenced predicate operation when a predicate REFERENCE is selected. A STRING predicate retains all applicable expression diagnostics.
    Result schema: result.collection

core.sort
    Meaning: Return LIST[T] in one declared deterministic total order from LIST[T] or SET[T].
    Determinism category: derived
    Determinism source: Derived from operators_and_functions_v0.1.0.json#/ordered_types, #/ordered_type_rules, the registered property-access projection or validated key operation, original LIST source position for ties, and the distinct-key rule for SET members: every valid invocation resolves deterministic; an invocation that cannot satisfy those rules fails.
    Possible dependencies: {declared_state_only}
    Possible effects: {none}
    Invocation resolution: Resolve natural order, one property_path, or one validated deterministic side-effect-free key operation whose fully resolved dependency set is exactly declared_state_only. No invocation may add a dependency or effect.
    Error resolution: Union the local errors with every applicable error of the referenced key operation when a key REFERENCE is selected.
    Result schema: result.collection
    Sort contract: Accept LIST[T] or SET[T] directly and return LIST[T]; no prior SET-to-LIST conversion exists.
    Key contract: Omit only for mutually order-compatible members. Otherwise use one exact property_path STRING through the registered property-access expression for a STRING key, or REF to a deterministic side-effect-free kind.operation with fully resolved dependencies exactly {declared_state_only}, exactly one compatible input, and one concrete registered ordered result.
    Tie contract: Equal-key LIST members retain source order. Distinct SET members must produce distinct keys. No comparator or stable parameter exists.
    Error contract: Exact triggers are registered for unknown, duplicate, positional, stable, or comparator operation parameters; an invalid direction type; key references; MISSING or UNKNOWN keys; malformed property paths; incompatible key-operation signatures; absent total order; incompatible keys; SET key collision; and invalid key-operation axes or profile resolution.

core.group
    Meaning: Partition one LIST by one declared key, preserving deterministic group and member order.
    Determinism category: deterministic
    Determinism source: The exact deterministic key partitions every LIST member into exactly one group; groups follow first key occurrence and members retain source order.
    Possible dependencies: {declared_state_only}
    Possible effects: {none}
    Invocation resolution: Resolve STRING key as exactly one property_path under field_signatures_v0.1.0.json, or REFERENCE as the registered deterministic side-effect-free key operation with dependencies exactly declared_state_only. A key result of MISSING produces error.required.missing and UNKNOWN produces error.value.unknown. No invocation may add a dependency or effect.
    Error resolution: Union the local errors with every applicable error of the referenced key operation when a key REFERENCE is selected.
    Result schema: result.value
    Group contract: STRING key is one exact property_path. result.value.value is a LIST of closed {key, items} records; items is LIST[T]. Strict == determines groups, first key occurrence determines group order, and every input occurrence appears once in source order. Empty input gives an empty group-record LIST.

core.verify
    Meaning: Check observable postconditions.
    Determinism category: derived

    Possible dependencies: {host, network}

    Result schema: result.verification

core.return
    Meaning: Return one declared value to the invoking channel.
    Determinism category: deterministic
    Determinism source: The returned value equals the exactly resolved target value.
    Possible dependencies: {declared_state_only}
    Possible effects: {none}
    Invocation resolution: Resolve only the declared material value or REFERENCE. A REFERENCE that does not resolve exactly once produces error.reference.unresolved; one that resolves to MISSING produces error.required.missing, and one that resolves to UNKNOWN produces error.value.unknown. Returning a material value adds no effects.
    Result schema: result.value
