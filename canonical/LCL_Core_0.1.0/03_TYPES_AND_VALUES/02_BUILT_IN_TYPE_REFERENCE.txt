LEARNED COMPUTING LANGUAGE (LCL)
TITLE: Built-in Type Reference
LANGUAGE VERSION: 0.1.0
STATUS: NORMATIVE
DATE: 2026-08-30


STRING
    Unicode text; no interpolation.

INTEGER
    Unbounded signed whole number. It never wraps, saturates, or overflows to a
    different LCL value.

DECIMAL
    Exact finite base-10 decimal with an unbounded integer coefficient and a
    finite non-negative count of fractional digits. Infinity, NaN, and
    underflow-to-zero are not DECIMAL values.

BOOLEAN
    TRUE or FALSE; no truthy coercion.

NULL
    Explicit known absence.

LIST[T]
    Ordered collection using bracket value syntax; duplicates allowed. INTEGER
    indexes are zero-based and out-of-range indexes return MISSING.

SET[T]
    Homogeneous collection unique under strict equality and intrinsically
    unordered. Source or insertion order has no semantic meaning, and equal source
    members collapse to one member. Direct FOR EACH is legal only when every pair
    of actual members is mutually order-compatible under the registered total-order
    profile and then uses canonical ascending order. Otherwise pass the SET directly
    to core.sort and iterate the returned LIST[T].

OBJECT
    Keyed value checked by an explicit schema when provided.

ENUM
    Closed domain of exact ITEM values introduced by DEFINE BASE ENUM and
    selected as REF(type.id). A transparent alias preserves the domain.

REFERENCE[T]
    Exact typed reference expressed with REF(identifier). Source notation is
    REFERENCE[REF(identifier)]; contextual identity versus bound-value reads
    follow types_v0.1.0.json#/reference_context_contract.

PATH
    Absolute path or path relative to an explicit WORKSPACE; a resolved
    workspace-relative path cannot escape its WORKSPACE root.

URI
    Absolute URI with a scheme under the RFC 3986 absolute-URI profile; relative
    references are invalid.

GLOB
    Workspace-relative file-selection pattern under the closed LCL GLOB profile.

REGEX
    Regular-expression pattern under the frozen closed LCL REGEX 0.1.0 grammar
    and matching rules in types_v0.1.0.json#/pattern_profiles/REGEX.

DATE
    RFC 3339 full-date value.

TIME
    RFC 3339 partial-time with an optional offset; an omitted offset means UTC.

DATETIME
    RFC 3339 full-date and partial-time with an optional offset; an omitted offset
    means UTC.

DURATION
    Non-negative amount of elapsed time.

PERCENTAGE
    DECIMAL from 0 through 100 inclusive.

BYTES
    Non-negative exact byte count.

MEASURE
    Number paired with one registered unit identifier; registered time-category
    units are permitted.
