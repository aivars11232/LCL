core.create
    Meaning: Establish an authorized target with the declared content or type.
    Determinism category: deterministic
    Determinism source: The target pre-state, content or target type, fail-if-exists flag, and selected target profile fix the required post-state.
    Possible dependencies: {host, network}
    Possible effects: {filesystem, network, state}
    Invocation resolution: Classify a REFERENCE target by the address class of its resolved target, never by REFERENCE syntax. PATH mutation adds host dependency and filesystem effect; URI mutation adds network dependency and network effect; OUTPUT or another authorized non-filesystem, non-network, non-memory, non-STATE addressable target adds state effect and its required dependency. MEMORY and STATE targets are prohibited; use core.memory_write or core.state_update.
    Result schema: result.operation

core.copy
    Meaning: Establish a destination containing an exact copy of a source.
    Determinism category: deterministic
    Determinism source: The destination content equals the exact source pre-state, the source remains unchanged, and overwrite behavior is fixed.
    Possible dependencies: {host, network}
    Possible effects: {filesystem, network}
    Invocation resolution: Classify a REFERENCE source by the address class of its resolved target, never by REFERENCE syntax. Resolve source observation dependencies and destination mutation effects independently under the selected copy profile: any URI side adds a network dependency and network effect for the primary copy; any PATH side adds host dependency; a PATH destination adds filesystem effect; observing a PATH, MEMORY, STATE, OUTPUT, or other host-bound source adds its required dependency but no source-side effect.
    Result schema: result.transfer

core.move
    Meaning: Relocate a target without changing declared content.
    Determinism category: deterministic
    Determinism source: The destination equals the exact source pre-state, the original address is absent, overwrite behavior is fixed, and the selected move profile is fixed.
    Possible dependencies: {host, network}
    Possible effects: {filesystem, network, state}
    Invocation resolution: Classify a REFERENCE source by the address class of its resolved target, never by REFERENCE syntax. Resolve source and destination address classes independently; the selected move profile chooses rename or verified copy-delete strategy. A PATH side adds host dependency and PATH mutation adds filesystem effect; a URI side adds network dependency and URI content relocation adds network effect; removing OUTPUT or another authorized non-filesystem, non-network, non-memory, non-STATE addressable source adds state effect and its required dependency. MEMORY and STATE sources are prohibited; use core.memory_write or core.state_update.
    Result schema: result.transfer

core.execute
    Meaning: Run an exact command, program, task, phase, sequence, action, or test.
    Determinism category: derived
    Determinism source: Derived from the exact invoked command, program, or referenced execution graph and the immutable profile required by axis_contract.implementation_profile: non-graph mode copies the execution profile's final category; graph mode copies the graph's final category.
    Possible dependencies: {host, network, model, human}
    Possible effects: {filesystem, network, process, package, message, memory, state}
    Invocation resolution: A PATH, URI, or STRING executable target and its exact arguments, working directory, and environment select exactly one immutable execution profile under axis_contract.implementation_profile. Every such non-graph invocation has the process effect because it runs the executable; union process with any other dependencies and effects selected by the profile within this row's maxima. A referenced TASK, PHASE, SEQUENCE, ACTION, or TEST has no mandatory local process effect and resolves the final determinism category and normalized transitive dependency and effect unions of its reachable graph under axis_contract.implementation_profile.graph_resolution.
    Error resolution: For a graph target, union the local errors, including error.reference.cycle for a prohibited graph cycle, with every applicable error of every reachable operation; for a non-graph target, use the local errors.
    Completion contract: Record completion through result.command without requiring a graph target to synthesize non-graph command observations. Result field cardinality and mode projection remain deferred to LCL-TASK-0005.
    Result schema: result.command

core.uninstall
    Meaning: Remove declared software or resources.
    Determinism category: deterministic
    Determinism source: The exact installed-target snapshot, purge-data flag, and selected package profile fix the required removed state.
    Possible dependencies: {host, network}
    Possible effects: {filesystem, process, package}
    Invocation resolution: Resolve host and optional network from the selected package profile, including its remote-management variant, and resolve filesystem, process, and package effects from that profile's removal transaction. purge_data FALSE preserves declared associated data; purge_data TRUE removes all declared associated data in authorized scope.
    Purge contract: On success the target installation is absent. purge_data FALSE preserves declared associated data; purge_data TRUE makes all declared associated data in authorized scope absent.
    Result schema: result.operation

core.publish
    Meaning: Make declared content externally available.

    Possible dependencies: {host, network}

core.upload
    Meaning: Transfer declared content to an external destination.
    Determinism category: deterministic
    Determinism source: The exact source snapshot, checksum, destination, overwrite flag, selected transfer profile, and implementation version fix the transfer contract.
    Possible dependencies: {host, network}
    Possible effects: {filesystem, network}
    Invocation resolution: Resolve source observation dependencies and destination mutation effects independently under the selected transfer profile: a PATH source adds host dependency but no filesystem effect; a URI destination adds network dependency and network effect for the primary upload; a PATH destination adds host dependency and filesystem effect.

core.download
    Meaning: Transfer declared content from an external source into scope.
    Determinism category: derived
    Determinism source: Derived from source pinning or mutability, the optional checksum, source profile, destination snapshot, and selected transfer profile: the invocation is deterministic exactly when the source profile fixes one immutable source identity and content snapshot and both source and transfer profiles are deterministic; otherwise it is nondeterministic.
    Possible dependencies: {host, network}
    Possible effects: {filesystem, network}
    Invocation resolution: Resolve the source profile, transfer profile, and destination PATH independently: a remote source adds network dependency and network effect for the primary download; a local source adds host dependency but no network effect; the destination PATH adds host dependency and filesystem effect.
    Result schema: result.transfer

core.memory_write
    Meaning: Create or update explicitly authorized persistent memory data.
    Determinism category: deterministic
    Determinism source: The exact MEMORY snapshot, declared value, merge flag, storage profile, and implementation version fix the post-state.
    Possible dependencies: {host}
    Possible effects: {memory}
    Invocation resolution: Resolve the authorized MEMORY storage profile. When merge is FALSE, replace the stored value exactly. When merge is TRUE, require the current and new values to be OBJECT, form the union of their top-level field names, use the new value for every same-name field, preserve the current value for every other field, and do not recurse into nested OBJECT values.
    Result schema: result.operation
    Merge contract: merge FALSE requires the replacement to match the declared MEMORY type. merge TRUE is shallow and right-biased: current and new values must be OBJECT, new same-name top-level fields win, untouched current fields remain, nested OBJECT values are not recursively merged, and the computed merged OBJECT must match the declared MEMORY type even when the patch OBJECT alone does not.

core.state_update
    Meaning: Update explicitly authorized STATE data.
    Determinism category: deterministic
    Determinism source: The exact STATE snapshot, declared value, atomic expected-before guard, storage profile, and implementation version fix the post-state.
    Possible dependencies: {host}
    Possible effects: {state}
    Invocation resolution: Resolve the authorized STATE storage profile, including its transaction variant, and enforce expected_before atomically when supplied.
    Result schema: result.operation
