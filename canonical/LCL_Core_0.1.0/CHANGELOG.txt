LCL CORE CHANGELOG

0.1.0 BARE LANGUAGE RELEASE - LCL-TASK-0007

- Retired the reference lexer/parser, semantic interpreter, and executable
  conformance tasks as outside the LCL Core 0.1.0 project scope, and replaced the
  final task with static validation, integrity regeneration, and bare-language
  release packaging.
- Revalidated the released bytes statically: path/mode hygiene, UTF-8 and LF
  hygiene, strict JSON parsing with duplicate-key rejection, Python source
  compilation, static EBNF graph closure, fifteen concrete source fixtures,
  thirty-three example contracts, fifteen registry and cross-registry closure
  gates, and the 797-entry requirements index.
- Confirmed that parser and executable-semantic evidence is classified
  OUT_OF_SCOPE rather than PASS or BLOCKED, and that release readiness is
  computed from FAIL and BLOCKED counts only.
- Corrected release documentation that still described a frozen, unpublished
  candidate, and corrected generate_integrity.py, which hard-coded a
  blocked-repair-candidate manifest status.
- Regenerated MANIFEST.json, then VALIDATION_REPORT.txt, then SHA256SUMS.txt from
  the released bytes in the documented acyclic order.
- Packaged the release archive outside the package root, verified archive
  integrity, extracted it, compared it byte-for-byte with the release tree, and
  revalidated the extracted copy.

0.1.0 BARE-SPECIFICATION-COMPLETE CANDIDATE - LCL-TASK-0006

- Reproduced the accepted Claude handoff decisions against the actual local
  candidate; no web-session edit was assumed present.
- Closed deterministic diagnostic selection across seven stages with one
  severity, exact specificity and same-cause supersession, independent
  multiplicity, exact duplicate identity, canonical omission locations, stable
  ordering, primary/secondary propagation, and declared-handler recovery.
- Distinguished missing required fields and duplicate blocks or fields from
  their generic cardinality consequences, including precise same-iteration and
  same-retry-attempt suppression identity.
- Resolved allowed failure phases for all 77 registered errors and specified
  producer-relative status, effect-state, observed-effect, OUTPUT-binding,
  retained-evidence, recovery, and indeterminate-state behavior.
- Preserved RETRY syntax for every resolved ACTION while requiring exact safety
  evidence after known effects, reconciliation after indeterminate effects, and
  actual failed attempts before error.retry.exhausted.
- Corrected the four accepted invalid-example expectations, pinned their exact
  source and expectation bytes, and added block-local and unresolved-reference
  static checks without claiming parser or semantic execution.
- Expanded the descriptive requirements index to 797 entries, including exact
  diagnostic-policy and failure-lifecycle requirements, and added twelve
  concrete deterministic selection vectors plus cross-registry lifecycle checks.
- Closed LCL-AUDIT-014 and LCL-AUDIT-015 and classified the language-definition
  scope as BARE_SPECIFICATION_COMPLETE. MANIFEST.json, SHA256SUMS.txt, and
  VALIDATION_REPORT.txt remain deliberately frozen and stale; no repair archive
  was produced.
