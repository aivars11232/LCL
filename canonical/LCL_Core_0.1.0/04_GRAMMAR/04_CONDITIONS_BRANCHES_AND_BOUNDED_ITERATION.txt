LEARNED COMPUTING LANGUAGE (LCL)
TITLE: Conditions, Branches, and Bounded Iteration
LANGUAGE VERSION: 0.1.0
STATUS: NORMATIVE
DATE: 2026-08-30


    IF (condition) THEN:
        STEP:
            ID: step.true_branch
            ACTION: REF(action.one)
    ELSE:
        STEP:
            ID: step.false_branch
            ACTION: REF(action.two)

ELSE is optional and aligned with IF. Branch bodies contain STEP, nested IF,
nested FOR EACH, or COMMENT.

    FOR EACH item IN REF(input.items):
        STEP:
            ID: step.process_item
            ACTION:
                ID: action.process_item
                OPERATION: core.inspect
                TARGET: REF(item)

The collection is finite before iteration. LIST iterates in source order. Direct
FOR EACH over SET is legal only when every pair of actual members is mutually
order-compatible under the registered total-order profile and then iterates in
canonical ascending order. Otherwise the SET must be passed directly to core.sort
and the returned LIST iterated. FOR EACH has no key or comparator syntax; those
rules belong only to core.sort. No WHILE, UNTIL, recursion, or unbounded repetition
exists. Nested declaration IDs create runtime instances suffixed by deterministic
iteration indexes while retaining one source ID.
