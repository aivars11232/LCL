LEARNED COMPUTING LANGUAGE (LCL)
TITLE: Collections, Objects, Enums, and Equality
LANGUAGE VERSION: 0.1.0
STATUS: NORMATIVE
DATE: 2026-08-30


LIST equality requires equal element type, length, order, and recursively equal
members. SET equality ignores source order and compares unique members. OBJECT
equality requires equal schema/field set and recursively equal values; field
source order does not affect equality. ENUM values compare by exact identifier.

STRING equality is code-point exact. Numeric equality allows INTEGER-to-DECIMAL
promotion only. MEASURE comparison requires the same UNIT; no implicit unit
conversion. REFERENCE equality compares resolved declaration identity.
