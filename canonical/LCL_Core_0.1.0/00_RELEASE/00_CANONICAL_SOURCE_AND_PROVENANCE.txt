1. CANONICAL SOURCE

This package root is the only canonical source tree for LCL Core 0.1.0. It
originates from the repair candidate produced by LCL-REPAIR-0001. Earlier
snapshots were packaged and subsequently repaired by Tasks 0001 through 0010.
The September 5, 2026 completion closes the current bare-language specification.
Language meaning is determined by the artifacts inside this tree under
00_RELEASE/02_NORMATIVE_AUTHORITY_ORDER.txt. Files
outside this package root are not normative inputs to the language.
